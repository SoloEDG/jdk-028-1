# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8028 。

## 总线与可复用子电路

- **位宽 1–16 位**：输入/输出可设 1–16 位；基础门（AND/OR/XOR/NOT/NAND/NOR）对整条总线逐位工作，所有输入必须与输出同宽。
- **切片与拼接**：`SLICE` 从总线取出连续若干位（设置起点/宽度）；`CONCAT` 把 2–16 段总线拼成一条。
- **圈定为子电路**：在工作台框选（或 Shift 多选）元件后点“圈定为子电路”。跨越选区的连线自动变为边界端口，可在对话框里改名、定位宽表达式与声明参数（如 `N`、`2*N`、`N-1`）。保存后选区替换为一个实例，并像普通门一样在元件库中放置。
- **位宽推导**：实例参数由外部接线推导，不要求逐个端口猜宽度，也不会静默补零。同一实例的端口宽度由一条线性约束系统联立求解；有多个可行解时列出选项并可切换，若约束冲突则给出跨嵌套的约束链。
- **嵌套**：子电路内部可以再放实例，参数表达式可引用外层参数（例如内层 `M = K`）。直接与间接递归都会被拒绝。
- **版本升级**：库中修改端口或参数会发布新版本；已有实例继续使用固定版本。可只升级某个实例，升级前会预览端口、参数、接线与目标检测变化；删除在用端口或位宽不兼容时会列出需要先处理的线路并阻止升级，失败实例保持原样。端口改名、调序按稳定端口身份沿用接线，不会错接。
- **内部观测**：进入实例可查看该实例内部的信号；两个实例的内部观测互不影响，可逐层进入嵌套实例。
- **持久化与兼容**：导出/重开会保留定义版本、实例参数与端口身份；旧版单比特 `.json` 仍可直接导入并按原接法运行。
